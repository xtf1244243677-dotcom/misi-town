# 《谜思小镇》主线谜题多样性与 M11–M25 设计规划

**日期：** 2026-09-26  
**状态：** 本文保留十五关的初期设计方向。M11–M25已全部制作，静态编译通过，尚未完整试玩；实际题面、答案及逐阶段推导以《谜思小镇-主线M11-M15关卡制作稿-v1.md》《谜思小镇-主线M16-M25关卡制作稿-v1.md》为准。后续M26–M30亦已接入，另有制作稿；本文规划表不作为当前关卡数据。  
**依据：** 玩家要求后续主线题型多样，不能反复依赖时间和方位；由制作方主动提出、筛选和落实设计。

## 1. 本次调整

M04–M10 七关中有五关使用时间配对，结案也多次采用报时或先后关系。玩家已确认这批关卡流程正常，但流程通过不代表题型分布合格。

后续必须同时改变“玩家需要推什么”和“证据怎样支持结论”。换人物、换地点、把到场顺序改叫交接顺序，不能算新增题型。

从此前 Murdoku 机制拆解中继续吸收“多条约束相互作用”和“可见物件具有实际推理用途”。主线将这种方法用在人物、物品、凭证和事件关系上；档案馆保留地图、参照物、障碍与区域推理。现有拆解不是对网站全部关卡的研究记录，不据此声称已经覆盖其题库。

## 2. 后续主线制作约束

1. **先有案件矛盾，再选择表格类别。** 不先套时间表，再编一段故事解释表格。
2. **相邻两关的核心推理机制不同。** 每连续五关至少包含四类机制；填表、结案分别统计。
3. **M11–M25 中，以时间或方向排序为核心的关卡合计最多两关。** 当前提案只安排一关时间机制。时间、地点可以出现在叙事里，但不能偷偷成为每关的主要解法。
4. **每关有明确的证据用途。** 封签、票据、印章等若用于推理，必须展示或说明具体特征及其规则；不得靠职业、动物种类或常识猜答案。
5. **变化不能只出现在最后一题。** 填表阶段也要轮换交叉排除、成组条件、数量对应、物品流转、信息兼容等方法。
6. **结案问题独立成立。** 填表结束后提供完整题设及每位相关人物的一条证词，证词集中保留；不要求回忆已消失线索，不靠物品名称直接泄露答案。
7. **不反复套“只有一人说谎”。** 可以使用矛盾、守恒、证据来源、必要条件、解释竞争等方法。真假人数仅在题目明确给出时作为条件。
8. **故事线索准确且可读。** “或者”说明是否允许两者都成立；“只有”与“只要”不混用；因果结论必须有足够的排他条件。
9. **新尺寸和新机制分开加难。** M11 首先适应五名人物；每关最多重点引入一种陌生逻辑规则，后面再组合。
10. **每阶段必须能推下去。** 已收起线索的必要信息应已变成确认关系或常驻规则；不能让后续推理依赖玩家记住一条消失的原话。

这些是后续设计要求，不追溯声称现有关卡已经全部满足。

## 3. M11–M25 题型安排

全段为 5×5。表内维度均按五名相关人物、每类五个互不重复的选项设计；两张表以同一组人物为关联基础。具体答案需在制作稿中另行确定。

| 关卡与暂定题名 | 填表类别 | 填表的主要推理方式 | 独立结案问题方向 |
|---|---|---|---|
| M11《拆开过的募捐箱》 | 人物×保管箱；人物×领取封签 | 封签特征与凭证的交叉排除，适应五人关系表 | 完整封签与替换记录能排除哪些解释，哪只箱子确实被重新封过？ |
| M12《借来的作案工具》 | 人物×借出工具；人物×归还工具 | 借出人与实际归还人分离，追踪一轮物品流转 | 工具所有者是否被冤枉；新提供的借据和使用痕迹指向谁实际使用？ |
| M13《少掉的一笔善款》 | 人物×摊位；人物×收款金额 | 售出份数、单价和退款相互制约；只用简短整数运算 | 复核新提供的账目，缺款发生在退款、交接还是汇总环节？ |
| M14《两封不能同时成立的邀请》 | 人物×邀请函；人物×携带礼物 | 成组条件与互斥关系；首次明确教会“恰好一个成立” | 五人各提供一项独立事实，哪一版邀请内容与全部事实兼容？ |
| M15《画框里的替身》 | 人物×经手画作；人物×包装材料 | 图案、包装与出借登记的跨类别匹配 | 正面照片、背面修补记录和馆藏特征共同证明哪件展品被替换？ |
| M16《镜片上的裂纹》 | 人物×送修物件；人物×领取凭条 | 物件与损坏特征的兼容性排除，规则来自本关检查单 | 裂纹在送修前还是返还后出现；哪项索赔与证据冲突？ |
| M17《重复兑付的奖券》 | 人物×奖券图案；人物×领取奖品 | “满足条件才可兑换”的必要条件与逆向排除 | 编号、存根与兑换记录交叉，哪笔兑付使用了重复凭证？ |
| M18《谁替谁签了名》 | 人物×代交文件；人物×使用印章 | 授权关系与签收身份分离，检查有向关系 | 五人证词配合本关明确的授权范围，哪一项签收越权？ |
| M19《被剪开的演出服》 | 人物×戏服；人物×修补材料 | 材料成组排除；剪下碎片与修补登记的关系 | 依据完整事故记录，哪一处损伤是人为破坏，哪一处是正常改衣？ |
| M20《午夜钟声的证人》 | 人物×记录时刻；人物×记录设备 | 已知设备误差下的相对先后；本批唯一以时间为主的关卡 | 多种记录的可靠范围交叉，哪份不在场证明无法成立？ |
| M21《不该出现的内部消息》 | 人物×收到的文件版本；人物×交回的附件 | 信息包含关系：每个版本独有的内容与附件对应 | 谣言包含哪一版独有的信息，哪位证人声称的消息来源不可能？ |
| M22《封箱前后》 | 人物×托运箱；人物×重量记录 | 数量守恒、统一包装重量和称重记录交叉 | 结合全新的封箱见证，货物短少与包装差异如何区分？ |
| M23《无法同时成立的证言》 | 人物×保管物；人物×签收回执 | 跨类别一致性；将两项间接排除串成推理链 | 不预设说谎人数，找出不能同时成立的一对证词，再用独立物证判别冲突点 |
| M24《遗嘱附件的去向》 | 人物×领取副本；人物×归还附件 | 两组对应关系与内容完整性约束；排除拆分错配 | 结合本关明示的委托与封存规则，谁有意隐匿了关键附件？ |
| M25《最后一页理赔书》 | 人物×申报物品；人物×提交凭证 | 综合凭证兼容、数量核对与跨类别排除 | 五人提供完整事实，区分误填、重复申报与伪造，指出唯一能被证实的欺诈 |

M15、M25 是各自小段的综合关，组合此前用过的技能，不靠增加陌生规则制造突增。涉及损坏、失踪或犯罪的结论须由事实支持；持有工具、缺少授权或说错一句话，不自动等于实施犯罪。

## 4. 前五关的制作重点

### M11：让证物特征参与推理

- 案情：募捐箱外观完整，清点人却发现其中一只可能重新封过。
- 表格任务：确定五名保管人各自保管哪只箱子、领取哪种封签。领取记录和案发后实物特征要分开，不能把“领取过”写成“必然用过”。
- 线索写法示例：“送来月纹箱的居民领走了叶纹封签；阿梨的领取存根上没有叶纹，也没有星纹。”后续需与其他关系合并才形成确认目标。
- 结案另给现场照片说明、封签批次及五份证词，推断哪只箱子重新封装。填表答案不得直接等于该答案。
- 先使用已有交叉排除方式，帮助玩家适应第五名人物；封签图案出现时必须配名称，不能只靠颜色辨认。

### M12：区分“是谁的”和“谁用过”

- 案情：破坏现场留下一件借来的工具，登记上的主人首先受到怀疑。
- 开局明确范围：本次活动恰有五件工具，每人借出一件、归还一件，每件恰好被归还一次。只描述这一轮记录，不能用一个格子代表多人多次接手。
- 线索写法示例：“周叔归还的是阿梨借出的那件工具；阿梨归还的不是自己的，也不是林老板借出的那件。”
- 结案重新提供完整的使用记录和相关证词，区分所有权、代还和实际使用；若只能证明使用，问题就只问使用者，不擅自升级成破坏者。

### M13：账目也是证据

- 案情：义卖总额对不上，各摊位都称已经交足。
- 采用五种不同收款金额，写明现金、退款和交款的统计口径。玩家算的是简单数量关系，挑战来自多条记录如何对应。
- 线索写法示例：“阿梨卖出六份点心，每份三枚镇币，其中一份原价退回；她交回的钱已经扣除了这笔退款。”该线索给出一个教学锚点，其余关系需要交叉推理。
- 结案使用另列的交接收据和五份证词核对差额；实际出题前明确是否存在零钱、手续费或未记账支出，不能隐瞒影响答案的条件。

### M14：让条件关系进入故事

- 案情：两版邀请函对活动安排的说明冲突，有人借此冒领礼物。
- 以一条清楚的规则引入互斥，不使用大量逻辑术语。示例：“登记员核实：‘阿梨拿着金边邀请函’和‘周叔带来蜂蜜’这两件事恰好一件属实。”
- 真假约束必须与其他确定事实形成可解链，不能让玩家通过扣命测试真假分支。
- 结案不是再出一遍相同互斥题；改为判断哪版邀请内容能容纳五人给出的全部事实，题设明确哪些记录已经核实。

### M15：第一次综合证物辨伪

- 案情：画展中一幅作品疑似被替换，但包装、印章和画面照片各自看上去都合理。
- 填表把包装材料和经手画作联结起来；必要的图案、标签、背面特征同时提供文字说明。
- 结案提供两种以上可能解释及能区分它们的证据，玩家判断“替换”“修复”或“登记错误”。每位人物的证词都须贡献证据，不能用四句陪衬围着一句直接答案。
- 本关总结特征交叉、物品经手和记录一致性；不额外加入方向、时钟误差或新图形规则。

本节中的示例句只说明线索风格，尚未组成可发布题目，不作为答案唯一性的证明。

## 5. 接入顺序和实现边界

1. 为 M11–M15 写完整数据稿：五名人物、两类各五个选项、目标关系、所有动态线索阶段、独立结案证词和解释。
2. 对每阶段记录“已知事实 → 候选缩小 → 必然确认项”。检查必要信息是否因线索消失而丢失；需要长期使用的规则放入常驻案情说明。
3. 将主线当前固定四人、四列的布局改成按人数配置，完成 5×5 的表格、头像、选项与证词阅读适配，保留原有确认交互。
4. 关卡结构保持一对一关系表。借还链使用“借出工具”“归还工具”两个独立维度；如果需要多次转手或一物多人，先明确新增数据与界面需求，不能硬塞入单选格。
5. 当前判题核心依赖预设答案，并不会自动理解线索文字。作者提供答案不等于题目唯一可解；完整制作稿必须列出推导依据，验证状态如实记录。
6. 先交付 M11–M15 成套内容，依据试玩反馈调整阅读负担与难度，再制作 M16–M25。两批均按本文件的多样性约束执行。

现有 A06–A10 第二案仍处于已接入、未完整试玩状态；本文件更新后续主线方向，不改变其验收记录。

## 6. 每批交付应说明什么

- 五关各自的核心机制，哪些是首次出现、哪些是组合复用。
- 填表与结案分别需要连接哪些证据，不能只列故事名称。
- 完整题设和逐阶段必然确认项是否已经人工推导；若有工具验证，明确覆盖范围。
- 代码接入、静态编译、自动验证、实际试玩分别记录，不能互相代替。
- 角色形象沿用角色注册表；新证物若需要图片，制作并接入与其文字描述相符的素材。
