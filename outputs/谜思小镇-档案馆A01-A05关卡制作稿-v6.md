# 《谜思小镇》档案馆 A01–A05 关卡制作稿 v6

**本版调整：** A01–A05 定为档案馆正式版案件 1 的五关原型；每关加入一处图像硬障碍，A01 的落位已修正为符合 4×4 的行、列和 2×2 分区规则。完成首轮审题，补齐 A02 的时间证据，明确 A03、A04 的首个可推导落位，修正 A04 参照物矛盾，并让 A05 的通道和结案证据能由文字对应。玩家线索使用证词、记录和物证叙述，不直接报行列号。  
**尺寸路线：** A01–A02 为 4×4，A03–A04 为 5×5，A05 为 6×6。  
**共同规则：** 每份材料恰好放入一个格；每行、每列、每个索引分区最多放一份。标有“封”字的图像障碍不可落位。盘面上北下南、左西右东。

## 难度目标与动态线索

- A01 是档案馆入门卷，但同尺寸逻辑难度比主线高两个档位：首个定位用于进入规则；之后要组合故事线索、图像障碍和行、列、分区排除。
- A02 继续使用相对位置与参照物，要求先由已确认记录排除整行、整列或分区。
- A03–A04 增至 5×5，同色索引组与跨带方位关系交叉；A05 使用 6×6 并叠加多份卷宗之间的证据关系。
- 线索仍按正确落位分批出现；答错扣命。失败重开清空本局落位和线索推进，已解锁卷宗保留。
- 设计目标是逐级增加推理步骤，不能靠隐藏规则或盲猜增加难度；A01–A05 的实际难度仍需要玩家试玩校准。

## 本版审题要点

- A03、A04 第一条动态线索改为相对窗户的明确邻接关系，避免首个确认落位依赖对“窗边/附近”的猜测。按当前答案表手工核对，A01–A05 的行、列和分区占位均不重复，障碍格也没有压在标准答案上。
- A02 的沈医生离开时间差现在明确写在线索中；A03 的结案文字只说明材料能证明的交接缺口，不再提前断言死因。
- A04 补充许姨口供与采访速记的时间冲突，并写明门房说明的迟交顺序；东门和封存采访桌的定位关系与棋盘参照物一致。
- A05 把索引页与书架西侧通道直接关联；经手凭据、同号封签和修改登记共同给结案判断提供文本证据。
- 每关标准答案仍需通过完整试玩确认唯一性和无猜测推进；“比同尺寸主线高两个档位”仍是设计目标，未作为已达成结果。

## 玩家可见线索与推理

### A01《旧宅四人档案》

1. 周岚的证词：散席时她一直守在北窗下；那扇窗开在旧宅北墙最靠西的一间房。
2. 西侧长廊上的书架在雨夜倒塌，封住了靠墙的格位；林记者的速记本紧挨着书架内侧。
3. 速记本留在南半部最靠北的一道档案带，与北窗房间隔着一间空房。
4. 许姨的门房笔记在速记本东北侧一间；她回到北侧房间时，记者还没有赶到。
5. 东门门牌上的红印来自许姨的门房登记；那份笔记紧贴门槛西侧。

周岚的北窗位置由证词与窗户图标相互印证。倒塌书架的图像占据西廊格，红色“封”标记阻止玩家把记录放在障碍上；速记本贴着障碍内侧，再与“南半部最靠北”的证词交叉锁定。许姨的位置由速记本的东北关系和东门门牌的红印共同确认；最后用行、列和 2×2 分区规则推出沈医生的位置。

### A02《暴雨夜的访客簿》

1. 访客簿封皮被暴雨泡皱，门房的红色印章盖在索引图最靠北、最靠西的角格。
2. 门房笔记夹在访客簿所在档案带以南、紧邻的那一道带里。
3. 门房笔记上的红泥印落在封闭书架与门房桌之间。
4. 记者的速记记着，沈医生离开旧宅的时刻比结案摘要晚了一刻；登记副本收在速记所在档案带以南紧邻的一道书架区。
5. 登记副本放在西侧书架区；访客簿已经占了最靠西的那一列。

门房笔记依赖访客簿的南侧关系，再结合棋盘上书架与门房桌之间的空位。后两条分别提供南北次序、西侧范围和离开时间差；结合已占用的西列与行列限制，可排出记者速记和登记副本。时间差说明原始记录与摘要不一致，但不能单独证明有人故意改写。

### A03《诊疗室的旧清单》

1. 出库清单页角沾着北窗的灰，档案员记得它夹在北窗正东、与窗同一横带紧邻的格位。
2. 值班员回忆：交接单收在比封存柜更靠北的位置。
3. 交接单在贴有“封”字的配药台（封台）正北方，与封台处在同一竖排。
4. 封存检验页的蜡印压在封存柜所在的那道横带上。
5. 检验页在交接单西侧；两页边角的同色索引印不能重叠。
6. 归还记录在检验页南边、出库清单东边；封存配药台挡住了它东邻格。归还单的入柜栏有勾记，却缺少签收编号；签收回执则夹在它更南边的档案带里。
7. 签收回执边角沾着诊疗室台阶的泥，是最后送回档案柜的一份。

交接单需结合画面上的封存柜与封台定位：比封存柜更靠北，且与封台处在同一竖排；再排除已经放入出库单的横排，得到唯一落位。此处不再使用画面未标出的“北侧两道档案带”。检验页结合封存柜所在横带、西侧关系及同色分区排除。归还记录的邻接关系与封存配药台共同确定位置，也为更南边的回执留出位置。归还单留下入柜勾记，却没有对应签收编号，当前材料不足以判断是谁动过物品。

### A04《三份口供》

1. 周岚的调查备忘夹在北窗正东、与窗同一横带紧邻的一格；纸边还留着被雨水晕花的报时记录。
2. 许姨说，她的正式口供被收在索引盘北侧的两道档案带里。
3. 门房记得那份口供紧贴东门内侧；门外就是外墙，没有多余的房间。
4. 林记者的采访速记和封存的采访桌留在同一道横带；桌面已经贴上封条，不能放入材料。
5. 采访速记记下沈医生离开的时刻比许姨口供早了一刻；速记夹在许姨口供的西侧，两份材料的同色索引印不能重叠。
6. 采访速记背面写着：沈医生的陈述夹在南侧紧邻的档案带，隔着一列在电话机以西。
7. 门房的补充说明是在雨停后最后补交的一份，封口仍带着当夜雨渍；它压在最南端的档案带。

采访速记由采访桌横带、许姨口供西侧、时间记录和分区排除共同确定。沈医生陈述再结合采访速记的南侧相邻带、已占位置和同色组排除归位。门房说明是雨停后最后补交的记录，位置由最南档案带和剩余行列约束确认。

### A05《被抽走的结案页》

1. 账目副页从卷首被抽出，留下的红印压在索引盘最北、最西的角格。
2. 许姨找到的卷宗索引夹在账目副页以南紧邻的档案带。
3. 索引页在账目副页以东，正夹在中央书架西侧紧邻的通道格；手绘圈标记也落在那条通道上。
4. 林记者找到的结案页被移入卷宗索引以南紧邻的档案带。
5. 结案页在索引以东，靠近东门，却没有贴着最外侧柜板。
6. 沈医生的经手凭据夹在结案页南侧紧邻的档案带，位于账目柜右侧的西半边；签字确认他在病发当夜领走一份封存诊疗包。倒塌书架封住这带最东侧的一格。
7. 封存信封在经手凭据以南紧邻的档案带，封条贴着封存柜西侧的书架通道；里面留有与诊疗包同号的封签，但归还记录缺少对应签收编号。
8. 修改登记压在装订台所在的最南一带，签字抵着最东侧的装订边；变更栏记着结案后有人改写诊疗包记录，签名处是沈医生。

6×6 关卡要求连续组合相邻档案带关系、书架参照、东门内侧、账目柜位置和分区排除。摆回六份材料后，玩家再把前四卷的访客时间差、物品登记缺口与口供冲突，同沈医生签收诊疗包的凭据、同号封签和结案后修改记录上的签名交叉核对，判断责任人。

## 故事边界与制作状态

档案馆追查乔先生旧宅死亡案。A01 复原在场位置；A02 核对访客时间；A03 核对诊疗物品；A04 交叉比对证词；A05 汇总账目与结案材料。剧情允许出现谋杀和疑似投药，但不展示现实中可复现的毒物、剂量或操作方法。

本版 A01–A05 均配置一处图像障碍，并与相关线索相连。玩家提供的 A05 试玩截图显示 6×6 棋盘、物件图像和“封”标记正常显示；玩家点按障碍格后，该格没有变成选中格，符合预期。该运行观察只覆盖 A05；A01–A04 的障碍触控、五关完整流程、答案唯一性和无猜测推进仍待逐项验证。正式版目标是同尺寸难度比主线高两个档位，目前仍是设计目标。
