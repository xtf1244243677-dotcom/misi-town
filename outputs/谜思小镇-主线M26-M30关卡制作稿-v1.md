## 2. M26 花房里的空种袋

机制：有限整数和差＋包装分类；结案为有控制条件的对照试验。

| 居民 | 种子 | 袋数 |
|---|---|---|
| 阿梨 | 豌豆 | 4 |
| 周叔 | 金盏花 | 7 |
| 米娅 | 薄荷 | 2 |
| 林老板 | 勿忘草 | 6 |
| 小禾 | 向日葵 | 5 |
| 沈馆长 | 南瓜 | 3 |

阶段推导：

1. 米娅、沈馆长合计5，取值2至7且不重复，只能2与3，米娅少→2。
2. 沈馆长比米娅多1→3。
3. 3袋对应大包种子，沈不是薄荷→南瓜。
4. 米娅2袋，另一种大包→薄荷。
5. 阿梨、小禾合计9，剩余数量4、5、6、7中仅4＋5；阿梨少→4。
6. 阿梨中包且非向日葵→豌豆。
7. 小禾比豌豆物主多1→5。
8. 中包另一种→向日葵。
9. 林、周只剩6、7，林少1→6。
10. 林小包非金盏花→勿忘草。
11. 周袋数剩7。
12. 周种子剩金盏花。

结案：相同批次、数量、水温条件下，干燥＋光照、干燥＋遮光均发芽；潮湿＋光照、潮湿＋遮光均不发芽，并有重复。优先排查潮湿存放，不能推出光照致损，更不外推全部植物。防雨布损坏是结案后的发现，不是隐藏答题条件。

## 3. M27 被调换的旅行袋

机制：物主与容器分离，跟踪连续置换。

| 居民 | 物品 | 现在的袋子 |
|---|---|---|
| 阿梨 | 相机 | 星袋 |
| 周叔 | 茶罐 | 叶袋 |
| 米娅 | 围巾 | 月袋 |
| 林老板 | 手套 | 山袋 |
| 小禾 | 画册 | 花袋 |
| 沈馆长 | 笛子 | 波袋 |

常驻交换链：原叶画册、星茶罐、花相机。先叶↔星，再星↔花，结果叶茶罐、星相机、花画册；月围巾、波笛子、山手套不变。

阶段顺序与理由：阿梨相机（与小禾的画册配对排除）→星袋；小禾画册→花袋；周叔茶罐（沈持笛子）→叶袋；沈笛子→波袋；米娅围巾（非成双手套）→月袋；林手套→山袋。交换全文保留在案情规则，不要求回忆已消失提示。

独立结案：甲面具、乙斗篷、丙手杖、丁铃铛，依次甲乙、乙丙、甲丁换内容。最后甲铃铛。说明每次交换整份内容且箱牌不变。

## 4. M28 拼花印章的缺口

机制：二维特征分类；结案为旋转不变量与证物相容。

| 居民 | 图形 | 边框 |
|---|---|---|
| 阿梨 | 空三角 | 波纹 |
| 周叔 | 实方 | 双线 |
| 米娅 | 实圆 | 锯齿 |
| 林老板 | 空方 | 虚线 |
| 小禾 | 实三角 | 点边 |
| 沈馆长 | 空圆 | 素边 |

阶段：

1. 阿梨、小禾持两种三角，阿梨不填色→空三角。
2. 米娅无角、实心类边框→实圆。
3. 实心边框中非点、非双→锯齿。
4. 小禾另一三角→实三角。
5. 小禾非双、锯齿已用→点边。
6. 周实心且非三角，实圆已用→实方。
7. 周实心边框剩双线。
8. 沈无直边，实圆已用→空圆。
9. 沈空心非波、非虚→素边。
10. 林图形剩空方。
11. 林边框非波、素已用→虚线。
12. 阿梨剩波纹。

结案：甲顺时针间隔两段且一个内环，符合原章。旋转半圈不会改变这两项；乙间隔错、丙无环、丁双环。只说相容，不把有限特征吻合直接视为作者鉴定。此版图形用清楚的文字分类，专用印样插画尚未制作。

## 5. M29 走错书袋的借阅卡

机制：有向委托关系＋跨表反查。特别区分“自借的书”和“替别人还的书”。

| 居民 | 自借书 | 替谁还 |
|---|---|---|
| 阿梨 | 航海记 | 小禾 |
| 周叔 | 修理册 | 阿梨 |
| 米娅 | 食谱 | 沈馆长 |
| 林老板 | 植物志 | 米娅 |
| 小禾 | 诗集 | 周叔 |
| 沈馆长 | 画集 | 林老板 |

阶段：

1. 阿梨代还小禾或周叔，周已委托小禾→阿梨替小禾。
2. 小禾代还周叔或自己，排除自己→周叔。
3. 周替阿梨或米娅，米已委托林→阿梨。
4. 林替阿梨或米娅，阿梨已被周代理→米娅。
5. 米可代还对象剩沈、林，非林→沈。
6. 沈代还对象剩林。
7. 阿梨带诗集或画集，画集由米代还；阿梨带诗集，自借者小禾。
8. 米带画集，自借者沈。
9. 周带航海或修理，修理由小禾带→周带航海，自借者阿梨。
10. 小禾带修理，自借者周叔。
11. 林带食谱或植物，非植物→食谱，自借者米娅。
12. 自借书剩林老板植物志。

结案：六项操作而非“六次人员交接”；最后一次只是换入沈的空书袋，小禾仍持书。答案小禾。题设已避免把“操作”全部预设为更换保管人。

## 6. M30 被擅改的闭幕节目

机制：允许道具集合逐步传递；结案为析取条件与例外辨认。

| 居民 | 节目 | 道具 |
|---|---|---|
| 阿梨 | 魔术 | 箱子 |
| 周叔 | 鼓乐 | 灯笼 |
| 米娅 | 舞蹈 | 旗帜 |
| 林老板 | 朗诵 | 书册 |
| 小禾 | 默剧 | 扇子 |
| 沈馆长 | 合唱 | 铃铛 |

阶段：阿梨允许书册但非朗诵→魔术，非书册→箱子；林允许书册但非魔术→朗诵，非灯笼→书册；小禾允许箱子但非魔术→默剧，箱子已用→扇子；米娅允许扇子但非默剧→舞蹈，扇子已用→旗帜；沈允许旗帜但非舞蹈→合唱，旗帜已用→铃铛；周剩鼓乐，道具剩灯笼。每一步使用的道具允许列表常驻，不随提示消失。

结案撤演条件为真火 OR（高台 AND 未检查）。甲、丙、己满足真火，乙、丁满足未检查高台；戊是冷光且高台已检查，两项皆不满足，撤演决定应纠正。六个候选对应六份证词，不按表格答案结案。
