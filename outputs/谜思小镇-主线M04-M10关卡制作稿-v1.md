# 《谜思小镇》主线 M04—M10 关卡制作稿

日期：2026-09-25；验收补充：2026-09-26。状态：数据与界面接入完成，TypeScript 静态编译检查通过。用户已确认 M04—M10 游玩流程无误，主流程记录为通过。

## 1. 本批范围

- 新增七个独立小镇案件，主线目录现在包含 M01—M10，全部采用两张4×4关系表。
- 每人、每个选项在同一表内均一一对应。每关有8个需正式确认的正向关系。
- 新七关各有开场、六阶段动态线索、独立结案证词、最终问题与解释。
- 结案证词不使用棋盘填写答案作为必要条件；材料归位后再集中展示，每位居民一条，选择后正式提交。
- 延续两条生命、一次模拟广告复活、暂填可改、确认判错、重开清空本局的规则。
- 本批复用茶馆、美术馆和灯塔背景，以及固定角色注册表中的既有头像。没有新增需要手工导入的图片。
- M01—M03 原有关卡及其旧式结案题本轮未改造；新七关采用独立证词结案页。

## 4. 六阶段推进的手工推演

每阶段确认指定的正向关系后，当前线索归档，下一组出现。已经提前正确确认的关系会在相应线索解锁后补处理。末尾剩余关系由一一对应规则推出，玩家仍需正式确认，才会进入结案。

### M04

1. 周叔→林老板→阿梨连续间隔十分钟，且阿梨不是末位，故阿梨09:20。
2. 周叔比阿梨早二十分钟，故09:00。
3. 剩余09:10、09:30，林老板早于米娅，故林老板09:10。
4. 最早交接者周叔拿纸袋。
5. 蓝盒排除林老板、米娅，周叔已拿纸袋，故归阿梨。
6. 米娅不拿木匣，在剩余布包、木匣中选布包。

### M05

1. 东厅排除小禾、沈馆长；陈警员在库房或长廊，故东厅只能是陆画师。
2. 库房排除小禾、沈馆长，又已有陆画师在东厅，故为陈警员。
3. 沈馆长在画室，剩余小禾在长廊。
4. 画室来客沈馆长拿钥匙。
5. 收据排除小禾、陈警员，沈馆长已有钥匙，故陆画师拿收据。
6. 长廊的小禾不拿手套，只剩丝带；陈警员拿手套。

### M06

1. 陈叔比苏禾晚二十分钟且苏禾不是首位，只能苏禾18:10、陈叔18:30；确认苏禾。
2. 重述苏禾与陈叔的间隔，再结合顾警长比陈叔早十分钟，确认顾警长18:20。
3. 剩余18:00、18:30，许医生更早，确认许医生18:00。
4. 最早签到者许医生拿节目单。
5. 票根排除顾警长、陈叔，许医生已有节目单，故苏禾拿票根。
6. 最晚的陈叔不拿哨子，只能拿工具袋；顾警长拿哨子。

### M07

1. 阿梨不是首位，且先于林老板一刻钟，周叔又晚于林老板，故阿梨14:15。
2. 米娅比林老板早半小时，排除已占用的14:15后，只能米娅14:00。
3. 剩余14:30、14:45，林老板早于周叔，故林老板14:30。
4. 糖罐不属于前三位，故归周叔。
5. 茶壶排除林老板、米娅及已有糖罐的周叔，故归阿梨。
6. 最早的米娅没拿封签，只能拿托盘，剩余封签归林老板。

### M08

1. 小禾不在东、西厅，库房又只能是陆画师或沈馆长，故小禾在办公室。
2. 东厅排除陆画师、沈馆长及已有办公室的小禾，故为陈警员。
3. 陆画师不在西厅，只剩库房；沈馆长在西厅。
4. 库房的陆画师带画框或目录，目录排除陆画师，故拿画框。
5. 西厅的沈馆长不拿邮封、手套，画框已被占用，故拿目录。
6. 陈警员没拿邮封，剩余手套归陈警员，邮封归小禾。

### M09

1. 陈叔→许医生→苏禾连续间隔十分钟，陈叔又不是首位，故陈叔20:10。
2. 许医生比苏禾早十分钟，在剩余时刻中只能为20:20。
3. 顾警长早于苏禾，在剩余20:00、20:30中只能为20:00。
4. 第三位到场者许医生拿称重单。
5. 苏禾、陈叔持有船票和油灯；陈叔的物品能照明，故拿油灯。
6. 苏禾不拿封签，在剩余选项中只能拿船票，封签归顾警长。

### M10

1. 从物品表开始。周叔不拿账册或印章，封存袋又归林老板，故周叔拿收据。
2. 收据持有人周叔比米娅晚十分钟，米娅不是首位、周叔不是末位，故周叔16:20。
3. 阿梨比持收据的周叔晚十分钟，故16:30。
4. 米娅比周叔早十分钟，故16:10；林老板16:00。
5. 印章不在首位林老板或末位阿梨手里，周叔已有收据，故印章归米娅。
6. 阿梨不拿封存袋，剩余账册归阿梨，封存袋归林老板。

此推演核对了预定推进路径的条件和答案；未运行自动求解，也未覆盖任意点击顺序的动态回合验证。

## 5. 独立结案答案与依据

| 关卡 | 结论 | 依据 |
| --- | --- | --- |
| M04 | 米娅 | 夜间取件链为阿梨20:00、周叔20:05、林老板20:10、米娅20:15；停电20:12 |
| M05 | 陆画师 | 留馆者集合与钥匙持有人、印章持有人集合相交，只剩陆画师 |
| M06 | 晚十分钟 | 慢五分钟的挂钟18:50对应18:55，加十分钟准备，到19:05；计划18:55 |
| M07 | 阿梨 | 依次假设阿梨、周叔、米娅、林老板换罐，假话数为1、2、3、0 |
| M08 | 修复后真品 | 背面印章排除登记复制品；衬纸水印排除未修复真品 |
| M09 | 净重一致 | 总重90－两只箱体18×2＝54，与发货净重54相符 |
| M10 | 林老板 | 依次假设阿梨、周叔、米娅、林老板偷换，假话数为3、1、3、2 |

M10 四句为：阿梨“凭证是周叔换的”；周叔“凭证是林老板换的”；米娅“阿梨和我都没有换凭证”；林老板“不是我换的”。题设明确恰两假，避免靠身份猜罪责。
