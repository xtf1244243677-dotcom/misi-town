题型：纸张属性与跨表配对；最终为字符串重叠拼接。角色继续使用阿梨、周叔、米娅、林老板、小禾、沈馆长的固定头像。场景借用美术馆图集。

## M42 总显示正常的检修台

题型：零件与工具的排他匹配；最终单一恒定故障诊断。场景复用灯塔，角色头像仍按人物ID，不随场景替换。

| 小禾 | 簧片 | 镊子 |

| 3 | 米娅—电笔 | 米/林拿电笔量尺；量尺只给插头保管者，米已是灯泡，排量尺。 |

| 9 | 周叔—扳手 | 扳手只给齿轮/插头；插头已经拿量尺，因此只能给齿轮。 |
| 10 | 小禾—镊子 | 簧片只能配镊子/量尺；量尺已用。 |
| 11 | 阿梨—烙铁 | 线圈/风叶用烙铁放大镜，烙铁不配风叶。 |
| 12 | 沈馆长—放大镜 | 工具最后剩余。 |

独立模块规则：P=A且B，Q=非C，R=P或Q；恰一个模块输出固定0或1，卡住输出也进入下游。六个故障候选为P0、P1、Q0、Q1、R0、R1。

| 候选 | 为什么保留/排除 |
|---|---|
| P卡0 | 六次观测均符合，保留。 |
| P卡1 | 观察到P=0，排除。 |
| Q卡0 | 输入000时正常P=0，若Q=0则R应0，实际1，排除。 |
| Q卡1 | 输入001时R应1，实际0，排除。 |
| R卡0 | 曾显示R=1，排除。 |
| R卡1 | 曾显示R=0，排除。 |

确定P卡0后，输入110：P=0、Q=1、R=1，选择第二项。后三组观测与模型相容，但前两组已经足够排除其他故障；它们展示覆盖不足，不伪称每条观测都必要。

如果题面没有“恰一处故障”，正常系统也满足前六组观测，预测新输入将不同，所以这一前提必须保留。没有假设实际电子元件的额外行为。

## M43 五枚放错盒的徽章

| 2 | 米娅—红线 | 三人红蓝白，蓝已用；周不是红，所以米红。 |

| 11 | 沈馆长—星点 | 星点装银线。 |

独立结案的盒/章排列：叶盒月章，月盒星章，星盒叶章，花盒波章，波盒花章，山盒山章。

三次方案：叶盒↔星盒，月盒↔星盒，花盒↔波盒。前三盒组成三循环需处理，后两盒互换，山盒原本正确。

最少性不只给一个方案：最初五只盒都错，两次交换至多涉及四只不同盒，至少一只原错盒根本没被触及，因此不能全对。下界3与三次方案一致。答案3，其他选项1/2不足，4不是最少。

## M44 荧光粉的实验记录

题型：数量乘积/和/大小与封签匹配；最终筛选有效对照、限制因果结论。

| 人物 | 份数 | 封签 |
|---|---|---|
| 苏禾 | 4 | 水纹 |
| 陈叔 | 2 | 藤叶 |
| 许医生 | 6 | 山峰 |
| 顾警长 | 1 | 星点 |
| 小禾 | 5 | 月牙 |
| 沈馆长 | 3 | 花瓣 |

| 阶段 | 唯一目标 | 推导 |
|---|---|---|
| 1 | 顾警长—1份 | 表头正整数1–6，乘积2只能1和2，顾更少。 |
| 2 | 陈叔—2份 | 与已知1份相乘为2。 |
| 3 | 许医生—6份 | 两数合11，只能5/6，许更多。 |
| 4 | 小禾—5份 | 11减已知6。 |
| 5 | 沈馆长—3份 | 剩3/4，沈较少。 |
| 6 | 苏禾—4份 | 唯一剩余。 |
| 7 | 顾警长—星点 | 少于3份的顾/陈用叶/星，星给更少的顾。 |
| 8 | 陈叔—藤叶 | 二选一剩余。 |
| 9 | 苏禾—水纹 | 苏4、沈3，水纹比花瓣多1，所以水纹给苏。 |
| 10 | 沈馆长—花瓣 | 二选一剩余。 |
| 11 | 小禾—月牙 | 月牙只给5份或2份；2份已有藤叶，故给5份。 |
| 12 | 许医生—山峰 | 最后剩余。 |

最终六条实验按“荧粉有无、温度、光照、容器、结果”：

| 编号 | 荧粉 | 温度 | 光照 | 容器 | 结果 |
|---|---|---|---|---|---|
| 甲 | 无 | 低 | 遮光 | 玻璃 | 不发光 |
| 乙 | 有 | 低 | 遮光 | 玻璃 | 发光 |
| 丙 | 无 | 高 | 遮光 | 玻璃 | 发光 |
| 丁 | 有 | 高 | 遮光 | 玻璃 | 发光 |
| 戊 | 无 | 低 | 照明 | 金属 | 不发光 |
| 己 | 有 | 低 | 照明 | 玻璃 | 发光 |

甲乙同时满足唯一变量是荧粉、结果不同。丙丁只变荧粉但结果相同；戊己同时变容器；甲丙变温度而非荧粉；乙戊同时改变荧粉/光照/容器；丁己改变温度/光照且结果相同。

前提明确其他条件一致，结论限于甲乙组合。丙是“没有荧粉也能发光”的已给反例，因此不能说荧粉是所有条件下唯一原因。此题和M26不是重复问哪一环境组有差异，而是从含混杂因素及相同结果的候选中筛出有效对照。

## M45 抽不到第二套的奖券

题型：奖品和封套之间的条件链；最终有限库存最坏情况保证。

| 人物 | 奖品 | 封套 |
|---|---|---|
| 阿梨 | 种籽 | 银色 |
| 周叔 | 书签 | 赤色 |
| 米娅 | 纸鸢 | 铜色 |
| 林老板 | 徽章 | 黑色 |
| 小禾 | 茶包 | 金色 |
| 沈馆长 | 画册 | 青色 |

| 阶段 | 唯一目标 | 推导 |
|---|---|---|
| 1 | 阿梨—种籽 | 阿/禾种籽茶包；茶包要金色，但阿仅银/赤，所以阿不能茶包。 |
| 2 | 小禾—茶包 | 二选一剩余。 |
| 3 | 小禾—金色 | 茶包用金色，本阶段重述。 |
| 4 | 阿梨—银色 | 银/赤二选一，赤只装书签；阿已是种籽，排赤。 |
| 5 | 周叔—赤色 | 周/米赤铜，铜只装纸鸢；周仅书签/画册，排铜。 |
| 6 | 米娅—铜色 | 二选一剩余。 |
| 7 | 周叔—书签 | 赤色只装书签。 |
| 8 | 米娅—纸鸢 | 铜色只装纸鸢。 |
| 9 | 沈馆长—画册 | 剩画册徽章，林不是画册。 |
| 10 | 林老板—徽章 | 最后剩余奖品。 |
| 11 | 沈馆长—青色 | 剩青黑，画册不用黑。 |
| 12 | 林老板—黑色 | 最后剩余封套。 |

结案库存红4橙4黄3绿2蓝2紫1，共16。不放回，要求两种不同颜色分别至少3张，求最少保证数。

若不达标，最多一种颜色能超过2张。将该颜色取最多4张，其他五色受上限和真实库存约束，最多2+2+2+2+1=9，总13。若没有任何颜色超过2，最多11，仍不超过13。

13张反例：红4橙2黄2绿2蓝2紫1，只红满3，尚不达标。抽第14张，无论余下橙或黄，都形成第二种满3颜色；一般上界已说明任何14张都达标。故14是最少。题面排除了把同色6张算两套，也不使用概率或平均值。
