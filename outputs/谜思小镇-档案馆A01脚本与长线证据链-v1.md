# 《谜思小镇》档案馆 A01 剧情脚本与长线证据链 v1

**用途：** 补充 A01 的叙事意图和档案馆长线的证据边界。  
**状态：** 本文早于五关可玩稿，个别后续关的构想仍属背景草案；当前游戏中实际题目、线索顺序、答案和结案文案，以《谜思小镇-档案馆A01-A05关卡制作稿-v6.md》及关卡数据为准。  
**当前真相：** 试玩线以沈医生为乔先生之死的责任人；A01–A04 只公布各自可推出的事实，A05 才综合揭示。

## 1. 旧案设定提案

多年前，小镇慈善家乔先生在旧宅聚会当晚死亡。最初结案记录写作突发疾病，但关键现场记录、访客时间和诊疗物品清单并不完整。多年后，档案管理员整理库房时发现一组被拆散的卷宗，把它们交给玩家逐份核验。

当晚与旧宅有关的四人沿用 A01 现有角色：调查员周岚、管家许姨、记者林、医生沈。A01 只复原四人在旧宅平面中的位置。后续档案将分别建立时间、物证、证词和动机，直到证据互相印证。

**候选最终真相：** 乔先生并非死于自然疾病，而是被人蓄意投药；沈医生利用其医生身份接触过相关诊疗物品，并在发现乔先生准备揭露救济金账目问题后，试图掩盖自己的挪用行为。此结论必须由后续多项独立证据共同支持，不能由职业、位置或单条记录直接推出。

**叙事边界：** 不描写真实可复现的毒物种类、剂量或操作方法。重点放在旧案材料如何互证、证词如何被误读，以及错误结案如何发生。

## 2. A01《旧宅四人档案》可制作脚本

### 档案入口卡

**标题：** 旧宅四人档案  
**副标题：** 一张没有标全的平面记录  
**卡片说明：** 旧宅聚会当晚的现场图只剩一部分。先复原四名相关人员的位置。

### 开场文本

> 这份卷宗属于多年前的旧宅死亡事件。结案摘要称，乔先生当晚因病去世，但现场平面记录缺少关键页。现存资料提到了调查员周岚、管家许姨、记者林和医生沈。先根据线索复原他们的位置。

**本关问题：** 谁位于东南区域？

### 开局线索

- 周岚在第 1 行第 2 列。

### 正确确认与线索出现

以下反馈只描述进度，不额外增加谜题条件：

| 玩家核实的关系 | 当前线索归档 | 新线索出现时的短反馈 |

| 周岚—第 1 行第 2 列 | 周岚在第 1 行第 2 列 | “周岚的位置核实了。档案背面还留有另一位在场者的坐标。” |

### 结案卡

**答案：** 沈医生。  
**标题：** 平面图复原  
**正文：**

> 沈医生位于东南区域。其余三人的位置也与平面图和现存记录吻合。这里确认的是位置，不是行动或罪责。卷宗还缺少访客簿、诊疗清单和口供，暂时无法说明乔先生当晚为何死亡。

**后续档案卡：** 暴雨夜的访客簿  
**提示：** 档案管理员从旧宅卷宗夹层找到一张访客簿索引。原始登记被存入镇政厅库房。

## 3. A02–A05 长线叙事意图

每关解决一个有限的问题，并在结尾陈述“本关证明了什么”和“仍然不知道什么”。以下是剧情层面的证据安排概述；可玩棋盘是档案材料在带有窗、门、书架等卡通物件插画的索引图中的位置复原，尺寸从 4×4 逐步提升至 5×5 和 6×6。逐关的当前实现和位置解见五关关卡制作稿 v5。

### A02《暴雨夜的访客簿》：建立机会，不定罪

**材料：** 门房访客簿、值班员交接表、结案摘要里的离宅时间。  
**当前关卡：** 将四份访客材料放回索引盘；正确回答东南区域中的材料。
**本卷可推出事实：** 沈医生实际离开时间晚于结案摘要所写；他有机会在乔先生死亡时间附近留在旧宅。  
**不能推出：** 留在现场不代表实施犯罪；时间差也可能来自登记或抄录错误。  
**进入 A03 的材料：** 访客簿记录显示，乔先生当晚使用的诊疗物品来自镇诊疗室。

### A03《诊疗室的旧清单》：确认物品链，不提供危险细节

**材料：** 诊疗室借出登记、值班交接清单、封存检验结论。  
**当前关卡：** 在 5×5 索引盘中结合北窗、东门、封存柜和台阶参照，归位五份诊疗材料，找出最后送回档案柜的签收回执。
**本卷可推出事实：** 一件与乔先生当晚有关的诊疗物品由沈医生经手，且其登记状态与交接表不符；复核样本提示乔先生并非单纯突发疾病。  
**不能推出：** 经手物品或样本异常本身仍不足以证明沈医生实施投药。  
**进入 A04 的材料：** 旧宅里的三份口供对物品何时进入房间有不同描述。

### A04《三份口供》：定位证词矛盾

**材料：** 许姨的管家笔记、记者林的采访速记、周岚当晚的调查备忘。  
**当前关卡：** 在 5×5 索引盘中结合采访桌、电话机和外廊参照归位五份材料，找出门房最后补交的证词。
**本卷可推出事实：** 许姨在较早的笔记中记下沈医生曾独自返回书房；正式口供却称当晚没有人返回。记者林的速记与周岚的时间记录能独立确认这段时间。  
**不能推出：** 单独一处口供矛盾可能源自记忆或记录错误，需结合动机和其他证据。  
**进入 A05 的材料：** 乔先生的账本副页与一份被抽走的结案页在同一卷宗袋中找到。

### A05《被抽走的结案页》：汇总并揭晓

**材料：** 乔先生的救济金账目、诊疗室经手记录的原件、被替换过的访客时间摘要、复核后的死因结论。  
**当前关卡：** 在 6×6 索引盘中归位六份结案材料，再回答谁应对乔先生之死负责。
**最终推理链：**

1. A02 的原始访客记录证明，沈医生在结案摘要声称他已离开之后仍留在旧宅。
2. A03 的登记链和独立复核材料证明，乔先生所用物品受到人为干预，且相关物品由沈医生经手。
3. A04 的独立记录证明，沈医生返回书房的时间与正式口供不符。
4. A05 的账目副页证明，乔先生准备公开救济金账目异常；沈医生的签名记录与资金缺口相连。
5. 被替换的时间摘要与被抽走的结案页说明有人试图把死亡定为疾病，并掩盖相关记录。

**拟定结论：** 证据共同指向沈医生蓄意投药并伪造部分记录。结案逐条回放证据来源，明确玩家是通过时间、物品、证词与账目的交叉验证得出结论，而非因为他是医生或曾在现场。

## 4. 证据强度检查表

| 推理问题 | 所需独立材料 | 不能只靠什么 |
|---|---|---|
| 是否为人为投药 | 复核死因 + 诊疗物品登记差异 | 不能只靠死亡现场有杯子 |
| 谁拥有机会 | 访客簿 + 至少一份独立时间记录 | 不能只靠棋盘上的房间位置 |
| 谁经手关键物品 | 原始登记 + 交接表或证词 | 不能只靠职业身份 |
| 谁隐瞒了行动 | 早期笔记 + 正式口供 + 第三份时间记录 | 不能只靠一次记忆错误 |
| 谁具有作案动机 | 账目副页 + 乔先生计划公开问题的记录 | 不能只靠欠债或一般争吵 |
| 最终责任人 | 上述证据链整体一致，且其他解释被排除 | 不能靠单一“决定性”巧合物证 |

若后续题目无法满足这些独立支撑，需改写案情或降低结论强度，不能让对白替代玩家应当解出的证据。

## 5. 与小镇主线的边界

- M01–M03 继续作为小镇单元案件各自结案，不因为 A01 的旧宅档案而被改造成同一阴谋的一部分。
- 灯塔案中的茶杯或死亡事件不会自动与旧宅案相连；只有未来设计出合理且可证明的交点时才建立联系。
- 玩家可以先推进小镇案件，再回档案馆继续旧案；两个进度分别保存。
- A01 结案后只解锁档案线索入口，不改变案件真相，也不直接宣布沈医生可疑或无罪。
