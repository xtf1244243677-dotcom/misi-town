# 《谜思小镇》档案馆 A01–A05 关卡制作稿 v4

**本版调整：** 将上一版线框符号替换为和档案馆美术一致的卡通物件插画；玩家线索使用证词、记录和物证叙述，不直接报行列号。解题需要结合线索、场景物件和棋盘约束。  
**尺寸路线：** A01–A02 为 4×4，A03–A04 为 5×5，A05 为 6×6。  
**共同规则：** 每份材料恰好放入一个格；每行、每列、每个索引分区最多放一份。盘面上北下南、左西右东。

参照物以卡通插画和名称出现在棋盘格内，用于理解“靠窗”“门内侧”“书架旁”等线索。插画素材为 `assets/resources/art/archive/archive-props-atlas-v1.png`，包含窗、门、走廊、书架、桌、柜、壁炉、电话和台阶九种物件。参照物本身不占用落位名额，允许记录落在带有参照物的格子。格子行列数字仅为操作定位，不出现在玩家线索里。

## 难度目标与动态线索

- A01 是档案馆入门卷，但高于 M01：除首份材料外，每个落位阶段至少需要合并两条线索，或将故事线索与行、列、分区排除结合。
- A02 继续使用相对位置与参照物，要求先由已确认记录排除整行、整列或分区。
- A03–A04 增至 5×5，同色索引组与跨带方位关系交叉；A05 使用 6×6 并叠加多份卷宗之间的证据关系。
- 线索仍按正确落位分批出现；答错扣命。失败重开清空本局落位和线索推进，已解锁卷宗保留。
- 设计目标是逐级增加推理步骤，不能靠隐藏规则或盲猜增加难度；A01–A05 的实际难度仍需要玩家试玩校准。

## 玩家可见线索与推理

### A01《旧宅四人档案》

1. 周岚的证词：散席时她一直守在北窗旁，椅子紧挨着西侧长廊。
2. 林记者赶到时宴席已经散场；他的速记本留在南半部最靠北、贴着长廊的那道房间。
3. 速记本贴着周岚房间西侧的墙，墙外就是走廊。
4. 许姨回忆，她是在林记者之前回到北侧房间的。
5. 许姨最后一次查看门廊时，站在最靠东的门边。

周岚的北窗位置由证词与窗户图标相互印证，西廊在棋盘左侧连续显示。林记者的两条线索分别锁定南北位置和西侧通道，再用周岚所在列及 2×2 分区排除确认。许姨的北侧位置与东门参照共同确定最后一位人物。

### A02《暴雨夜的访客簿》

1. 访客簿封皮被暴雨泡皱，门房的红色印章盖在索引图最靠北、最靠西的角格。
2. 门房笔记夹在访客簿所在档案带以南、紧邻的那一道带里。
3. 门房笔记上的红泥印落在书架与门房桌之间。
4. 记者的速记记着，沈医生的登记副本仍收在它更南边的书架上。
5. 登记副本放在西侧书架区；访客簿已经占了最靠西的那一列。

门房笔记依赖访客簿的南侧关系，再结合棋盘上书架与门房桌之间的空位。后两条分别提供南北次序和西侧范围；结合已占用的西列与行列限制，可排出记者速记和登记副本。

### A03《诊疗室的旧清单》

1. 出库清单页角沾着北窗的灰，档案员记得它夹在西侧窗边的格位。
2. 值班员的交接单收在索引盘北侧的两道档案带中。
3. 交接单放在出库清单东边，紧挨东门内侧、但没有贴着外墙。
4. 封存检验页的蜡印压在封存柜所在的那道横带上。
5. 检验页在交接单西侧；两页边角的同色索引印不能重叠。
6. 归还记录在检验页南边、出库清单东边；签收回执则夹在它更南边的档案带里。
7. 签收回执边角沾着诊疗室台阶的泥，是最后送回档案柜的一份。

交接单需将北侧档案带、出库清单和东门位置合并判断。检验页结合封存柜所在横带、西侧关系及同色分区排除。归还记录的南侧与东侧关系还要同时给更南边的回执留出位置。

### A04《三份口供》

1. 周岚的调查备忘夹在北窗旁，纸边还沾着西侧走廊的灰。
2. 许姨说，她的正式口供被收在索引盘北侧的两道档案带里。
3. 门房记得那份口供贴着东门内侧，旁边还留着一格空位通向外墙。
4. 林记者的采访速记被夹在采访桌所在的那道横带上。
5. 采访结束时，林记者站在许姨口供的西侧；两份材料的同色索引印不能重叠。
6. 采访速记背面写着：沈医生的陈述夹在南侧紧邻的档案带，隔着一列在电话机以西。
7. 门房的补充说明压在最南端的档案带，封口还带着当夜的雨渍。

采访速记由采访桌横带、许姨口供西侧和分区排除共同确定。沈医生陈述再结合采访速记的南侧相邻带、已占位置和同色组排除归位；门房说明由外廊位置和剩余约束确认。

### A05《被抽走的结案页》

1. 账目副页从卷首被抽出，留下的红印压在索引盘最北、最西的角格。
2. 许姨找到的卷宗索引夹在账目副页以南紧邻的档案带。
3. 索引页在账目副页以东；手绘圈标出了中央书架西侧紧邻的通道。
4. 林记者找到的结案页被移入卷宗索引以南紧邻的档案带。
5. 结案页在索引以东，靠近东门，却没有贴着最外侧柜板。
6. 沈医生的经手凭据夹在结案页南侧紧邻的档案带，位于账目柜右侧的西半边。
7. 封存信封在经手凭据以南紧邻的档案带，封条贴着封存柜西侧的书架通道。
8. 修改登记压在装订台所在的最南一带，签字抵着最东侧的装订边。

6×6 关卡要求连续组合相邻档案带关系、书架参照、东门内侧、账目柜位置和分区排除。摆回六份材料后，玩家才结合前四卷的访客时间、物品登记缺口与口供冲突判断责任人。

## 故事边界与制作状态

档案馆追查乔先生旧宅死亡案。A01 复原在场位置；A02 核对访客时间；A03 核对诊疗物品；A04 交叉比对证词；A05 汇总账目与结案材料。剧情允许出现谋杀和疑似投药，但不展示现实中可复现的毒物、剂量或操作方法。

本版关卡数据与场景棋盘已接入透明底物件插画，并保留小字标签；Creator 导入和预览中的清晰度、点击体验待玩家确认。谜题难度目标为高于 M01，并按 4×4、5×5、6×6 递增；需要试玩反馈继续校准。
