# 《谜思小镇》档案馆正式版关卡结构与 Murdoku 机制拆解

**版本：** v1 · 2026-09-25  
**用途：** 固化正式版 100+50 关目标，记录对用户指定网站的玩法观察，并作为档案馆原创关卡生产规范。  
**范围说明（2026-09-26 更新）：** 这是正式版路线图。当前 Cocos 已接入主线 M01–M15 和档案馆 A01–A10，仍属原型，不等于最终内容规模。各批编译与试玩状态以最新制作稿为准。

## 1. 已确认的正式版规模

### 档案馆相对主线的难度

档案馆与主线在相同棋盘尺寸下比较时，档案馆的逻辑难度目标高两个档位。这里的“高两档”指推理复杂度，不把关卡整体改成更大的棋盘，也不等同于多写两段线索。档案馆每案五关还要逐关上升，因此每案第 1 关已经比主线同尺寸段更考验推理，第 5 关则是本案高点，并且尺寸比第 1 关增加两行两列。

| 难度档位 | 设计标准 | 主线用途 | 档案馆用途 |
|---|---|---|---|
| 1 | 单条直接线索即可定位；一次排除 | 新规则教学 | 不作为档案馆常态 |
| 2 | 两条明示事实合并；短链排除 | 入门熟练 | 档案馆入门内容仍需超出此档 |
| 3 | 一次候选交叉或简单否定关系 | 主线标准关 | 档案馆第 1 关的最低逻辑门槛（比主线同尺寸高两档） |
| 4 | 两段推理；至少一种间接故事线索 | 主线进阶段 | 档案馆前段常态 |
| 5 | 三项约束交叉，使用区域或障碍排除 | 主线综合关 | 档案馆中段起点 |
| 6 | 多步候选链、否定线索与空间约束交汇 | 主线高难关 | 档案馆后段常态 |
| 7 | 证据链较长，需持续维护候选；仍可逐步证明 | 主线章节挑战 | 档案馆每案第 5 关的目标档位 |

上述档位先作为内容制作标尺，正式定级前要通过内部解题记录和玩家试玩校准。任何档位都必须唯一解、每个动态线索阶段都存在必然可确认项；难度不能依赖歧义、过度阅读或猜错扣命。

## 2. 对 murdokuonline.com 的机制观察

网站把人物安置在一张有区域、门窗、家具和其他图示的现场地图中。放置规则要求每行、每列各一人，线索再通过人物所在区域、与道具的邻接关系、相对方向等限制可能格。页面还清楚区分可站立物件、不可站立障碍，提供叉号标记与清空棋盘等推理工具。其帮助页强调人物线索必须成立，场景本身参与推理，而不是单纯铺在网格下方的装饰。

这个设计有效的部分：

1. **地图能参与推理。** 门、家具、房间分区和障碍物有明确用途；读线索时玩家需要回看棋盘。
2. **规则容易复用。** 行列唯一规则稳定，关卡通过改变地图、对象分布和线索组合形成差异。
3. **文字与图示互相校验。** 图片让空间关系一眼可见，文字说明负责精确表达规则。
4. **难度来自线索交互。** 更大棋盘增加候选格，但真正的挑战是多条关系彼此收紧，而不是只堆长文案。
5. **玩家能自行记录排除。** 叉号标记和清空操作支持试算，降低大棋盘的工作记忆负担。

对《谜思小镇》的借鉴方式是采用空间推理框架，不复制对方的具体关卡、线索句子、地图布局、角色、美术或关卡标题。档案馆的独立身份来自“整理旧卷、复原文件在索引盘上的位置、核查档案矛盾”，而非把原作的嫌疑人换名字。

## 3. 转化为档案馆玩法的设计规则

### 3.1 棋盘规则

- 格子是档案索引盘上的调查位置；档案材料或记录卡是待放置主体。
- 每个主体恰好放一次；行、列和本关定义的区域规则明确写在开局说明中。
- 场景参照物、可放置位置、硬性障碍必须视觉上区分，且其规则始终一致。
- 方向定义固定为上北、下南、左西、右东。涉及距离、相邻、同区或隔墙时，帮助页解释“相邻”的判定。

### 3.2 图像障碍分类

棋盘上的物件统一分成三类，不能让玩家仅凭图片猜规则：

| 类别 | 例子 | 能否放置 | 作用 |
|---|---|---:|---|
| 方位参照 | 北窗、门口、电话、楼梯 | 依关卡定义 | 支持“靠窗”“门旁”“电话以南”等故事线索 |
| 可用位置 | 书桌、椅子、阅览台 | 是 | 作为记录可能放置的位置 |
| 硬性障碍 | 倒塌书架、封锁绳、碎玻璃、堆满的纸箱 | 否 | 图片直接封住格子；其标签和图例说明不可落位 |

当前原型的窗、门、书架、桌子等插图是定位参照；帮助文案仍允许在相应格落位。因此图片资源导入不等于“不可落位障碍”已经完成。正式版需为障碍格添加数据标记、不可点击/不可确认反馈、图例和无障碍文本描述。障碍图片不能只作为装饰，也不能无说明地改变逻辑。

### 3.3 线索写法

- 让线索像从档案、证词、现场痕迹中读到的事实，例如“泥点从诊疗室台阶一路落到西侧长廊，最后停在封存柜旁”，然后由棋盘解释位置关系。
- 避免直接报“第几行第几列”。只在新手教学中短暂示范坐标，正式关卡改用方向、区域、物件、顺序、邻接和人物关系表达。
- 单条线索描述一个能核验的事实，避免一句话藏入多个未经教学的规则。
- 通过“谁留下了哪份材料”“两份记录先后出现在哪里”“哪张口供与现场记录相冲突”等档案目标推进剧情；对谋杀或下毒的结论由多类证据支持，不由图像、角色职业或单次接触暗示。

### 3.4 难度递进

| 关卡阶段 | 主要训练点 |
|---|---|
| 每案第 1 关 | 新案情、新棋盘规则；直接地标和少量单步排除 |
| 第 2 关 | 两条线索共同指向一个位置；首次出现本案障碍图示 |
| 第 3 关 | 位置关系与行列/区域规则交叉；需要保存候选 |
| 第 4 关 | 负向线索、顺序线索或跨区域排除；至少两段推理链 |
| 第 5 关 | 棋盘比第 1 关宽两格；综合本案已教学的规则并回答本案结论 |

每案最多新增一种主要规则。难度通过棋盘尺寸、初始锚点数量、线索间依赖深度、区域形状和障碍布局分开校准；避免同时加入大棋盘、陌生障碍和新型逻辑关系。

档案馆的目标难度比主线同尺寸高两档。执行时优先提高“线索组合后才收窄候选”的比例、跨区域/障碍的排除作用和必要推理链长度；不以冷僻词、长句、模糊叙述或故意隐藏规则制造难度。每关首次出现的规则仍要用图例或短说明教会玩家。

## 4. 超越参考作品的产品标准

“超越”不靠把棋盘无限放大，而靠证据质量、叙事兑现和可验证性：

1. **每关唯一解可机器验证。** 关卡数据要能表达行列限制、区域限制、对象邻接、方向、距离、不可落位格和顺序关系；编辑器或构建校验器枚举解答，必须恰好为一个。
2. **每条线索有证明作用。** 标出它排除或确定哪些候选格；去掉线索后若答案仍完全不变，应考虑删改，避免无效文本。
3. **动态线索阶段无猜测门槛。** 每次玩家能正式确认的位置，必须由当前已公开线索和此前正确结论必然推出；错误不能成为获得下一条剧情文本的必要代价。
4. **图像有规则语义。** 障碍格用遮挡或封条形状表达，参照物用小图标表达，可落位格保持清晰；同时给出形状、文字或图例，不只靠颜色。
5. **结案能复盘。** 完成后展示关键推理链：哪条证词、哪处图像障碍、哪次行列排除共同锁定了答案。
6. **案件独立可玩。** 每案开场重新提供角色、事件和规则所需事实；跨案彩蛋只增加情绪与世界感，不充当必需证据。
7. **10×10 仍适合手机。** 进入 8×8 以上时先做横向或分区视图、小格标记和候选查看的界面验证；不能把缩小字号当作默认方案。

当前原型的关键制作差距：答案数据可以判定某格是否正确，但正式版还需要独立的唯一解检查和线索逐步可解检查。A01–A05 已加入各一处图像硬障碍，规则会阻止落位；正式版制作还要让每处障碍都参与解题推理，并区分地标参照与不可落位物件。

## 5. 生产和验收流程

1. 先写案件事实、玩家最终要回答的问题和本案五关的推理技能表。
2. 先绘制棋盘：区域、方位参照、可用位置、图像障碍和标准答案。
3. 根据答案反向编写线索，再用求解器检查唯一解；不得先写一段故事再硬塞答案。
4. 按五个线索阶段检查每阶段至少存在一个可必然确认的选择，并检查错误提交不会导致卡关。
5. 独立审稿人只看线索和棋盘复原解答；另一名试玩者仅凭屏幕信息完成关卡。
6. 在目标手机尺寸检查可读性、障碍辨识度、点按范围、暂填与确认反馈。
7. 试玩数据用于调整文本长度和线索强度，不通过隐藏答案或随机改变已知事实拉难度。
