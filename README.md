## 项目结构

```text
assets/
  scenes/                 Cocos 场景文件（由 Creator 创建和保存）
  resources/art/          按场景组织的图集与运行时加载素材
  scripts/
    core/                 与引擎 UI 无关的回合状态、数据类型
    data/                 关卡题面、答案、线索编排
    services/             本地存档等平台服务
    ui/                   Cocos Creator 场景组件和交互界面
outputs/                  已审阅的 GDD、关卡稿与制作计划
work/                     临时分析和中间文件，不作为游戏资源
```

## 命名约定

- Cocos 项目包名使用小写英文与连字符：`misi-town`。
- 文件夹使用简洁的小写英文，按职责分层；新增玩法优先归入 `core`、`data` 或 `ui`，避免在 `assets/scripts` 根目录堆放文件。
- TypeScript 类/组件文件使用 PascalCase 并与主要导出同名；数据模块使用 camelCase，并以案件或关卡含义命名。
- 场景文件使用小写 kebab-case，例如 `main-story.scene`、`archive-room.scene`。
- 文档与交付稿用中文名称，统一放在 `outputs/`。

## 当前实现

- 每次挑战可通过广告或分享二选一领取一条提示，共用一次机会；主线、档案馆、放大棋盘和结案页都有入口。取消不消耗，刷新保留本局使用状态，重开恢复机会。当前是明确标注的模拟领取流程，未接入真实广告或分享SDK；新增流程仅静态编译通过，尚未试玩。

- `PuzzleSession` 提供临时填写、撤销/清空、正式确认、生命、一次复活、失败重开、动态线索推进和根据已确认答案推导的自动排除。
- `LocalProgressStore` 保存当前回合以便中断恢复；从案件列表进入一关或推进到下一案时，会清空目标案件的本局状态并重新开始，但保留已解锁章节。主线正确结案后解锁档案馆，档案馆提供返回小镇的入口。
- 主线案件目录新增每日挑战日历入口。日历以北京时间（UTC+8）标记日期，每天00:00开放当天关卡，未来日期锁定；过去日期可补玩，已完成日期可重玩但不重复领奖。每日回合按日期隔离，正确结案首次发放6枚小镇纪念章。当前所有日期复用D01《桂花糖罐去哪了》题面，D02–D07轮换、兑换商店和服务端校时尚未实现；日历界面与旧存档迁移尚未编译或预览。
- 主线 M01—M10 均为4×4，使用配置驱动的 `MainStoryPuzzleView`，由 `MainPuzzleGreyboxScene` 管理回合。新七关数据位于 `assets/scripts/data/mainStoryChapterOne.ts`，包含开场、动态线索和独立人物证词结案。案件目录每页五关，顺序解锁；M03 结案后开放档案馆和 M04，旧版档案馆已开放的存档会补开 M04。
- 主线 M11—M15 为5×5，数据位于 `assets/scripts/data/mainStoryChapterTwo.ts`，采用封签、借还、账目、条件关系和证物辨伪五种案件方向。新增“案情 / 规则”常驻入口，五名人物均使用既有固定头像；`mainStoryCaseBuilder.ts` 为 M04 起的关卡统一生成关系格与阶段。主线保存最高已完成关，供后续内容扩展衔接，重玩不撤销解锁。
- 档案馆 A01–A10 使用 `ArchivePuzzleView`，由 `ArchiveGridGreyboxScene` 管理回合；目录按每案五卷翻页，逐卷解锁，最高已完成卷与回合状态分别保存。第一案为旧宅往事，第二案为雾港失踪案。透明底物件图集为 `assets/resources/art/archive/archive-props-atlas-v1.png`；最新题目与检查记录见 `outputs/` 中对应案件制作稿。
- M01、M02、M03、A01 的谜题规则、答案与动态线索各自保存为关卡数据；回合存档按谜题隔离，案件切换时重置目标案件的回合状态。
- 两个灰盒组件均已挂接到各自场景的 Canvas，并在 Creator 中保存；《谜思小镇》UI 在运行时生成，广告复活目前为模拟流程。封面与主线路径概念图保存在 `outputs/视觉概念/谜思小镇-封面与关卡地图概念-v1.png`，档案馆作为独立侧入口呈现，主线第9关保持锁定标记。

## 在 Cocos Creator 中创建场景

1. 用 Cocos Creator 3.8.8 打开本文件夹并等待资源导入。
2. 打开 `assets/scenes/main-story.scene`，将 `MainPuzzleGreyboxScene` 组件挂到 Canvas 并保存。
3. 打开 `assets/scenes/archive-room.scene`，将 `ArchiveGridGreyboxScene` 组件挂到 Canvas 并保存。
4. 在项目构建设置中把 `main-story.scene` 设为启动场景，再预览主线场景。

两个场景骨架取自 Creator 3.8.8 随附模板，已导入、保存并挂接脚本；无需重复挂载。进入已开放案件会开启新一局并保留解锁进度。窗、门、书架等物件图集此前已导入，新增第二案继续复用。各批试玩状态见下方“当前试玩”。商店级进度和真实广告 SDK 仍待完成。
